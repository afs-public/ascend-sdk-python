# OpenLotLongShortIndicator

Indicates whether the lot is long or short.


## Values

| Name                               | Value                              |
| ---------------------------------- | ---------------------------------- |
| `LONG_SHORT_INDICATOR_UNSPECIFIED` | LONG_SHORT_INDICATOR_UNSPECIFIED   |
| `LONG`                             | LONG                               |
| `SHORT`                            | SHORT                              |
